## Sobre

O **Vitryne** é uma plataforma de moda regional que conecta consumidores a lojas físicas locais — boutiques, confecções e lojas de bairro. Catálogo digital, busca por proximidade, pagamento integrado e delivery, com modelo de prova e devolução em casa.

A próxima geração de marketplaces não é global. É **hiperlocal**.

## Explore

Nosso código está organizado em quatro repositórios públicos:

* [vitryne-backend](https://github.com/Vitryne/vitryne-backend) — API REST em Java e Spring Boot
* [vitryne-frontend](https://github.com/Vitryne/vitryne-frontend) — Aplicação web em React e TypeScript
* [vitryne-mobile](https://github.com/Vitryne/vitryne-mobile) — Aplicativo mobile em React Native e Expo
* [vitryne-docs](https://github.com/Vitryne/vitryne-docs) — Documentação técnica e acadêmica do projeto

Para reportar bugs ou sugerir melhorias, utilize as [issues](https://docs.github.com/en/issues/tracking-your-work-with-issues/creating-an-issue) do repositório correspondente.
