Lojas de moda locais são invisíveis online. O Vitryne dá a cada uma delas uma vitrine digital, com busca por proximidade, compra integrada e entrega em casa.

[Site](https://www.vitrynes.com) · [Documentação](https://github.com/Vitryne/docs) · [Como contribuir](https://github.com/Vitryne/.github/blob/main/CONTRIBUTING.md)

## Repositórios

* [Repositório backend](https://github.com/Vitryne/backend)| API de catálogo, pedidos, pagamento e entrega
* [Repositórios frontend](https://github.com/Vitryne/frontend) | Portal web do consumidor e painel do lojista.
* [Repositórios mobile](https://github.com/Vitryne/mobile)  | Aplicativo do consumidor e do entregador
* [Repositórios documentacao](https://github.com/Vitryne/docs) | Requisitos, diagramas UML, fluxos e arquitetura
